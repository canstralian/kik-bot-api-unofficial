# Security policy

This project is unofficial and should not be assumed to support current Kik authentication. Report suspected vulnerabilities privately to repository maintainers through GitHub's available private vulnerability reporting channel if enabled; otherwise contact the maintainer directly without posting secrets in an issue.

Never provide passwords, device IDs, auth stanzas, password-derived passkeys, private messages, tokens or captcha responses in reports. Provide a minimal offline reproduction with synthetic test fixtures. Do not conduct testing against people, accounts or groups without authorization.

Project policy: no TLS bypass, third-party credential endpoints, mass unsolicited messaging or bypasses of Kik verification/attestation. Supported CI runtimes are Python 3.10 and 3.11; release remains gated on separate live compatibility evidence. See docs/runbooks/operations.md.
